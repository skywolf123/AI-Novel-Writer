# AI 小说作家 1.1.0-fork.1

个人 fork 的快速构建版本，用于获取可直接运行的 Windows 安装包。应用内更新仍指向上游仓库，因此本 release 仅作下载用途，不作为应用更新源。

## 本版新增

1. fork 首个快速构建：内容基于上游 master（含合并 #223 移除活动栏等），本地无功能改动。
2. 新增独立的快速 Windows 打包工作流（quick Windows package）：仅产出安装包，不运行正式发布的资格门（验收回执、冒烟测试等），让 fork 能快速拿到可运行版本。

## 发布目标与安装提示

- 平台：Windows x64
- 安装包与标签指向同一提交（quick Windows package 工作流会校验并固定 tag 到实际打包的 commit）
- 该 release 不参与应用内自动更新
