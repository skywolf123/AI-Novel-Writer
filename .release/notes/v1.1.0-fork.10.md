# AI 小说作家 1.1.0-fork.10

个人 fork 的快速构建版本，用于获取可直接运行的 Windows 安装包。应用内更新仍指向上游仓库，因此本 release 仅作下载用途，不作为应用更新源。

## 本版新增

1. **AI 审稿重构为分片并行**：
   - 一次审稿拆为 4 个并行的专注 LLM 调用——事实线（剧情连贯/前后串联/伏笔完整）、因果与角色（合理性/角色状态）、叙事规范、章节目标逐项核对，单片只输出少量 JSON，大幅缓解输出截断（finishReason=length）与维度间注意力稀释。
   - 新增「叙事规范」检查维度：人称一致性（如第三人称叙事混入第一人称句）、视角越权、叙述时态滑动，逐句举证。
   - 审稿确认弹窗勾选的重点维度升级为分片路由：未勾选维度所在分片直接不调用，省时省额度。
   - 各分片独立重试替代输出；跨分片问题自动去重（同问题取更严重判定）后合并为一份报告，报告 UI 与「按审稿修稿」链路不变。
2. **确定性重复段落检测**：
   - 生成与修稿出口新增硬校验：模型异常复读、续写拼接重叠造成的整段逐字重复直接拒绝保存，不再静默入库。
   - 审稿报告并入重复检测结论（整段逐字重复=error、高度近似=warning）；短文本回环（如日期多次出现的刻意呼应）不会被误杀。
3. **AI 润色（全自动多轮）并入集成分支**：
   - 新增润色入口：全篇润色 → 质量门控判定 → 通过 / 整篇重润 / 定点修复（JSON 补丁逐字应用，机械保证只动问题区）。
   - 润色使用专属生成预算档并从流程常量推导；预算耗尽自动短路后续轮次。
   - 门控问题类型中文化（〔AI 痕迹〕〔节奏〕〔对话〕〔完整性〕〔结尾〕）；平局判定保留包含更多修复的晚轮稿。
4. **解除工作流单次请求输出上限硬编码**：按模型租约能力协商输出上限，审稿等长 JSON 输出不再被固定值顶截断。
