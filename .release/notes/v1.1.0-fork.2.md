# AI 小说作家 1.1.0-fork.2

个人 fork 的快速构建版本，用于获取可直接运行的 Windows 安装包。应用内更新仍指向上游仓库，因此本 release 仅作下载用途，不作为应用更新源。

## 本版新增

1. 批量创作中，模型供应商返回**瞬时错误**（限流、超时、5xx 等）改为按退避重试，不再直接丢弃整批未完成章节。
2. 修正批量工作流单次尝试的输出上限：原先对所有意图硬编码 8192 token，导致自身声明更大输出上限的模型仍按 8192 请求、以 `finishReason=length` 失败收场，且错误提示指向一个根本不会生效的设置。现提升到应用级上限，单次请求仍取「策略与模型能力声明」中的较小值。
3. 章节角色词表在两个选择器之间统一，并存库保持作者原文，不再把无法识别的角色回退成「建置」。

## 发布目标与安装提示

- 平台：Windows x64
- 安装包与标签指向同一提交（quick Windows package 工作流会校验并固定 tag 到实际打包的 commit）
- 该 release 不参与应用内自动更新
