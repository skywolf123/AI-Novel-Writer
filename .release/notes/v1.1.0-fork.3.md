# AI 小说作家 1.1.0-fork.3

个人 fork 的快速构建版本，用于获取可直接运行的 Windows 安装包。应用内更新仍指向上游仓库，因此本 release 仅作下载用途，不作为应用更新源。

## 本版新增

1. 批量创作新增第三种完成模式「AI 全流程定稿」（`ai_pipeline`）：整章无需人工确认跑完全流程——草稿 → AI 修稿（默认参数）→ 采纳合并 → AI 评审（默认关注点）→ 确认默认清单 → 按清单修订 → 采纳合并 → 定稿。每一步都以上一步的精确产出为输入，两次合并复用手动合并视图的同一数据库提交，批量章节的终态与逐章人工确认完全一致。评审与修订命令新增可选参数控制是否打开编辑器标签页，单章人工路径行为不变。
2. 自动定稿模式的警告文案修正：原先把结果描述成「提交只读章节」，混淆了状态变更与其编辑侧后果；现改为按顺序陈述——章节先定稿，随之只读。
3. 内部重构：评审报告解析与清单默认值抽取为独立模块，不改行为。

## 上一版已有（fork.2）

- 批量创作中供应商瞬时错误（限流、超时、5xx）按退避重试，不再丢弃整批章节。
- 批量工作流单次尝试输出上限不再硬编码 8192。
- 章节角色词表在两个选择器间统一，存库保留作者原文。

## 发布目标与安装提示

- 平台：Windows x64
- 安装包与标签指向同一提交（quick Windows package 工作流会校验并固定 tag 到实际打包的 commit）
- 该 release 不参与应用内自动更新
