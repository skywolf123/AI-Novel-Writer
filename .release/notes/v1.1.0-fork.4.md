# AI 小说作家 1.1.0-fork.4

个人 fork 的快速构建版本，用于获取可直接运行的 Windows 安装包。应用内更新仍指向上游仓库，因此本 release 仅作下载用途，不作为应用更新源。

## 改进

1. 章节蓝图续写现在会把每一前置章节的「主角小目标」（purpose）与「末尾悬念钩子」（suspenseHook）一并传给下一批生成，而不再只传「标题 + 关键事件」。承接上一章剧情时，模型能看到上一章想达成什么、留下了什么悬念。
2. 续写提示词新增一条接续规则：紧接上一章的钩子推进，但不要重跑已经达成的目标，也不要让上一章的钩子或目标原地复述（除非作者设定明确要求回扣）。
3. 单章紧凑回退路径同步补上 purpose，避免该路径与正常批次的前情信息不一致。
4. 前情摘要中每个字段都按蓝图语义合同的字段上限做有界截断，历史遗留的超长蓝图不会撑爆提示词预算。

## 说明

连续性与「黄金三章」等既有节奏规则保持不变；本次只扩展了传给模型的前情字段，不改动蓝图 JSON 合同、不改动落库结构。

## 发布目标与安装提示

- 平台：Windows x64
- 安装包与标签指向同一提交（quick Windows package 工作流会校验并固定 tag 到实际打包的 commit）
- 该 release 不参与应用内自动更新
