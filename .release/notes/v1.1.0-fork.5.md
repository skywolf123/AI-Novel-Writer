# AI 小说作家 1.1.0-fork.5

个人 fork 的快速构建版本，用于获取可直接运行的 Windows 安装包。应用内更新仍指向上游仓库，因此本 release 仅作下载用途，不作为应用更新源。

## 改进

1. 章节蓝图编辑器新增「新建空草稿」：在任意已有蓝图的章节上都能直接起一条空白手写稿，不再强制先走 AI 写作。
2. 该入口放在蓝图卡片顶部，不受「只有权威下一章才能写」的门禁限制；蓝图存在即可用，不会造出「有草稿无蓝图」的孤儿状态。
3. 空草稿在数据中标记为 `manual`，与 AI 生成（`write`）和历史版本回退（`rewrite`）区分开。
4. 重复点击不会堆叠空版本：若该章最新草稿本身就是空手动稿，直接复用并打开。
5. 空草稿不能定稿（定稿要求非空正文），因此只是手写逃生舱，不会污染定稿事实源与连续性投影。

## 说明

本次只新增一条手写入口与一个来源标记，不改动既有 AI 写作、修稿、审稿、定稿流程，也不改动草稿落库结构（`source` 列本就无 CHECK 约束，新增取值无需迁移）。

## 发布目标与安装提示

- 平台：Windows x64
- 安装包与标签指向同一提交（quick Windows package 工作流会校验并固定 tag 到实际打包的 commit）
- 该 release 不参与应用内自动更新
