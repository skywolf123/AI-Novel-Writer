# AI 小说作家 1.1.0-fork.6

个人 fork 的快速构建版本，用于获取可直接运行的 Windows 安装包。应用内更新仍指向上游仓库，因此本 release 仅作下载用途，不作为应用更新源。

## 本版新增

1. 已定稿章节不再允许「新建空草稿」：主进程在写入事务内直接拒绝，界面也会先行提示「本章已定稿，如需重写请先在正文章节删除这一稿」。同章出现第二份定稿会让权威序列判为重复、锁死后续所有章节的写作，且后处理数据按章节号覆盖、删除也无法回归，因此改为硬性阻断。
2. 批量创作中，模型供应商返回**瞬时错误**（限流、超时、5xx 等）改为按退避重试，不再直接丢弃整批未完成章节。
3. 重试退避期间的取消操作可被正确识别，不会把用户取消误记成供应商失败；重试收据改为累加，避免多次重试后计数丢失。
4. 章节角色词表在两个选择器之间统一，并存库保持作者原文，不再把无法识别的角色回退成「建置」。

## 上一版已有

- 章节蓝图编辑器的「新建空草稿」入口：任意已有蓝图的章节都能起一条空白手写稿，不受「只有权威下一章才能写」的限制，重复点击会复用已存在的空手动稿而不是堆叠版本。
- 空草稿在数据中标记为 `manual`，与 AI 生成（`write`）和历史版本回退（`rewrite`）区分；空草稿不能定稿，不会污染定稿事实源。

## 说明

本次不改动蓝图 JSON 合同与草稿落库结构（`source` 列本就无 CHECK 约束，新增取值无需迁移）。

## 发布目标与安装提示

- 平台：Windows x64
- 安装包与标签指向同一提交（quick Windows package 工作流会校验并固定 tag 到实际打包的 commit）
- 该 release 不参与应用内自动更新
