# AI 小说作家 1.1.0-fork.7

个人 fork 的快速构建版本，用于获取可直接运行的 Windows 安装包。应用内更新仍指向上游仓库，因此本 release 仅作下载用途，不作为应用更新源。

## 本版新增

1. 章节全自动多轮 AI 润色：新增润色命令与润色门禁（polish gate），每轮产出经过文稿质量校验后才可采纳，避免不合格的改写直接落入章节。
2. 润色对比视图增强：三栏合并视图新增行内字符级高亮——删除/新增的字分别着色，不再整行粗标；新增变更点上下导航（工具栏 ‹ › 按钮与计数、`Alt+↑`/`Alt+↓`、`F3`/`Shift+F3` 跳转、`Enter` 采纳当前变更），打开视图时自动定位第一处变更；超过 8 行的未变更区域默认折叠为首尾上下文，可一键展开；工具栏汇总全文 `+新增 −删除` 行数。
3. 移除两个无引用的旧 diff 组件（`DiffViewer` / `MonacoDiffViewer`），版本对比与润色对比统一走三栏合并视图。
4. 同步上游修复：订阅网关请求携带 opencode Go 会话头，且仅在生成会话中作用域生效，避免跨会话串写。

## 上一版已有（fork.6）

- 已定稿章节不再允许「新建空草稿」，主进程在写入事务内硬性阻断。
- 批量创作中供应商瞬时错误（限流、超时、5xx）按退避重试，不再丢弃整批章节。
- 重试退避期间的取消可被正确识别，重试收据累加不丢计数。
- 章节角色词表在两个选择器间统一，存库保留作者原文。

## 发布目标与安装提示

- 平台：Windows x64
- 安装包与标签指向同一提交（quick Windows package 工作流会校验并固定 tag 到实际打包的 commit）
- 该 release 不参与应用内自动更新
