# AI 小说作家 1.1.0-fork.8

个人 fork 的快速构建版本，用于获取可直接运行的 Windows 安装包。应用内更新仍指向上游仓库，因此本 release 仅作下载用途，不作为应用更新源。

## 本版新增

1. AI 润色可靠性修复：
   - 润色流程改用专属生成预算档，并从流程续写常量自动推导（最坏路径 15 次请求），不再复用单次修稿的文本档预算。此前整章润色加一次门控即耗尽会话预算，导致第 2/3 轮迭代必然失败；门限常量调整时预算自动联动，无需手工同步。
   - 润色门控的判定原因逐条进入运行日志：确定性命中（AI 高频词、解释腔等）与 LLM 问题清单均可见，不再只给出"局部修正"结论。
   - 会话级预算/次数耗尽后自动短路后续轮次，不再逐轮空转报错。
2. 合并视图增强：
   - 三栏合并视图按 hunk 导航（‹ › 按钮、快捷键）时同步显示光标位置，便于定位当前变更在全文中的落点。
   - 修复 diff 对话框头部高度，关闭按钮恢复垂直居中。
3. 发布流程改进：
   - quick Windows 打包工作流改为从 `.release/notes/<tag>.md` 读取发版说明，release 页面展示完整更新内容而非占位文本。
   - 回填 fork.1–fork.3 的历史发版说明。

## 上一版已有（fork.7）

- 章节全自动多轮 AI 润色：润色命令与润色门禁（polish gate），每轮产出经过文稿质量校验后才可采纳。
- 润色对比视图增强：行内字符级高亮、变更点上下导航（‹ ›、`Alt+↑`/`Alt+↓`、`F3`/`Shift+F3`、`Enter` 采纳）、大段未变更区域折叠、变更行数汇总。
- 移除无引用的旧 diff 组件，版本对比与润色对比统一走三栏合并视图。
- 同步上游修复：订阅网关请求携带 opencode Go 会话头，仅作用于生成会话。

## 发布目标与安装提示

- 平台：Windows x64
- 安装包与标签指向同一提交（quick Windows package 工作流会校验并固定 tag 到实际打包的 commit）
- 该 release 不参与应用内自动更新
