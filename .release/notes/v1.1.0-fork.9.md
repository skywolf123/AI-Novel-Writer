# AI 小说作家 1.1.0-fork.9

个人 fork 的快速构建版本，用于获取可直接运行的 Windows 安装包。应用内更新仍指向上游仓库，因此本 release 仅作下载用途，不作为应用更新源。

## 本版新增

1. 工作流日志可读化（全部流程生效，含写稿/修稿/审稿/润色/蓝图/角色架构）：
   - 不再直出内部枚举，`finishReason=stop` 等改为「正常完成」「达到输出上限」等可读短语；输出被截断时提示「自动续写第 N 段」。
   - 续写计数改用「段」，避免与润色轮次的「轮」混淆。
2. AI 润色运行日志本地化与修复：
   - 门控问题类型中文化（〔AI 痕迹〕〔节奏〕〔对话〕〔完整性〕〔结尾〕），门控判定附问题数量；不再出现中英混排。
   - 修复胜出稿平局判定：此前各轮确定性指标打平时会回滚到第 1 轮稿，导致后续轮次已成功应用的门控修复被丢弃；现在平局保留包含更多修复的晚轮稿。
   - 候选稿标签改为「第 N 轮…」，不再与修订链版本号 r1/r2 撞名。
3. README 新增「关于本 fork / 相对上游的增强」章节，从功能角度说明本分叉与上游的差异（中英双语）。

## 上一版已有（fork.8）

- AI 润色改用专属生成预算档并从流程常量自动推导，修复两次调用即耗尽会话预算导致迭代中断的问题。
- 润色门控的判定原因（确定性命中与 AI 问题清单）逐条进入运行日志。
- 会话级预算耗尽后自动短路后续轮次。
- 合并视图 hunk 导航显示光标位置；修复 diff 对话框头部高度。
- 快速打包工作流从 `.release/notes/<tag>.md` 读取发版说明；回填 fork.1–fork.3 历史说明。

## 发布目标与安装提示

- 平台：Windows x64
- 安装包与标签指向同一提交（quick Windows package 工作流会校验并固定 tag 到实际打包的 commit）
- 该 release 不参与应用内自动更新
