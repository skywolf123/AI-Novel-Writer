# AI 小说作家 1.1.0-fork.B

个人 fork 的快速构建版本，用于获取可直接运行的 Windows 安装包。应用内更新仍指向上游仓库，因此本 release 仅作下载用途，不作为应用更新源。

## 本版新增

1. **审稿分片开关与报告决策彻底对齐**：
   - 审稿确认弹窗由「4 个检查维度」改为「3 个分片开关」——事实线 / 因果与角色 / 叙事规范，一个勾选对应一整片 LLM 调用，标签与分片实际检查范围一致。
   - 分片路由不再依赖中文维度标签的字符串匹配，改为直接传分片键：即使自定义模板改动了措辞，路由也不会失配、不会静默漏审。
   - 叙事规范分片与其它分片一样可开关；章节目标核对始终执行，弹窗内以一行说明告知，无需（也不可）勾选。
   - 关闭某个分片即跳过该次调用，不再为该维度付出 token。

2. **失效的旧审稿模板清理**：
   - 移除已被分片取代的 `consistency_check` 内置模板（含其中英文 overlay 与可编辑列表项），避免用户误编辑一个不生效的模板。
   - 三个分片模板（事实线 / 因果与角色 / 叙事规范）保留在模板管理中，可自定义。

3. **批量流水线适配**：全自动批量流水线的审稿步骤改用新分片键接口取默认分片集合，与手动审稿行为一致。

## 上一版已有（fork.A）

- AI 审稿重构为 4 个并行专注分片（事实线 / 因果与角色 / 叙事规范 / 章节目标），缓解输出截断与注意力稀释。
- 新增「叙事规范」检查维度：人称一致性、视角越权、叙述时态滑动。
- 确定性重复段落检测：生成/修稿出口硬校验 + 审稿报告并入。
- AI 润色（全自动多轮）并入；解除工作流单次请求输出上限硬编码。

## 发布目标与安装提示

- 平台：Windows x64
- 安装包与标签指向同一提交（quick Windows package 工作流会校验并固定 tag 到实际打包的 commit）
- 该 release 不参与应用内自动更新
