# AI 小说作家 1.1.0-fork.F

个人 fork 的快速构建版本，用于获取可直接运行的 Windows 安装包。应用内更新仍指向上游仓库，因此本 release 仅作下载用途，不作为应用更新源。

## 本版修复

1. **删掉「本章目标」里那条没有内容的重复提示**：
   - 审稿报告的「本章目标」分类下，有时会出现两条：一条是带目标原文和具体判断的正常条目，另一条只有一句「本章目标来源或逐项核对不完整，请人工核实。」，没有任何目标内容。
   - 第二条不是模型报出的目标，而是软件在「目标逐项核对未通过校验」时补的一条通用横幅。它把「目标来源缺失」和「逐项判断没通过校验」两种完全不同的原因塞进同一句话，因此在最常见的那种情形下既重复又没有信息量——每条目标行其实已经各自写明了「该目标缺少有效的逐项判断或正文证据」。
   - 现在横幅只在**确实没有可核对的目标**（本章未配置关键事件、或蓝图读不到目标来源）时才出现，那才是它唯一能提供信息的场合。有逐项目标时不再追加。

## 上一版已有（fork.E）

- **审稿修稿循环收敛**：跨轮收敛度量（已修复/原文未动、未修复项置顶、「上轮已报」标记）；审稿修复改为定点补丁，不再整章重写；修稿时注入已定稿前文事实与角色状态。
- 注意：自定义过「审稿驱动修稿」模板的话需恢复默认（旧模板输出整章正文，不符合补丁合同）。

## 更早版本

- **fork.D**：修复"合并修订稿后立即审稿/修稿被拒"。
- **fork.C**：`max_tokens` 改为取 `min(模型配置输出能力, 上下文可用空间)`；取消会话级 token 累计预扣；删除全部按 token 量的门限与统计。
- **fork.B**：审稿分片开关与报告决策对齐；分片键路由；清理失效模板；批量流水线适配。
- **fork.A**：AI 审稿并行分片重构；新增「叙事规范」维度；确定性重复段落检测；AI 润色并入。

## 发布目标与安装提示

- 平台：Windows x64
- 安装包与标签指向同一提交（quick Windows package 工作流会校验并固定 tag 到实际打包的 commit）
- 该 release 不参与应用内自动更新
