# AI 小说作家 1.1.0-fork.I

个人 fork 的快速构建版本，用于获取可直接运行的 Windows 安装包。应用内更新仍指向上游仓库，因此本 release 仅作下载用途，不作为应用更新源。

## 本版修复

1. **修稿产物的多余空行自动折叠**：
   - 整章修订删除段落时，被删段落两侧的空行会残留为连续 2-3 个空行；删除类补丁同理。
   - 现在所有修稿产物（审稿修复的整章与补丁两种模式、「AI 修稿」）在保存前做一次确定性空行规整：连续 ≥2 个空行折叠为 1 个、统一换行符、去掉首尾空行——只动空白，不碰任何可见字符。
   - 已合并的旧修订不受影响；需要时在编辑器里手动替换多余空行即可。

## 本版沿用（fork.H）

- 总体修稿指导非空 → 整章全篇修订（独立模板「审稿全篇修稿」，输出整章纯文本，注入已定稿前文事实与角色状态）；留空 → 定点补丁修复。
- 蓝图「关键事件」一键拆分节拍按钮。
- 定点补丁的两条防发散规则：连锁同步、插入禁带新事实。

## 更早版本

- **fork.G**：全篇/补丁双模式与蓝图 keyEvents 节拍数组合同（fork.G 的整章模式输出 JSON 的缺陷在 fork.H 修复）。
- **fork.F**：删除「本章目标」无内容的重复覆盖率横幅。
- **fork.E**：审稿修稿循环收敛；自定义过「审稿驱动修稿」模板需恢复默认。
- **fork.C/D**：输出上限解耦、合并后状态同步等。

## 发布目标与安装提示

- 平台：Windows x64
- 安装包与标签指向同一提交（quick Windows package 工作流会校验并固定 tag 到实际打包的 commit）
- 该 release 不参与应用内自动更新
